# ROOTED 
### The Farm That Remembers

ROOTED is a climate-adaptive crop rotation decision-support tool
developed for the NASA Space Apps Challenge 2026.

The application combines NASA Earth observation data, local soil
information, crop characteristics, and farmer priorities to help
farmers explore climate-resilient crop rotation strategies.

## Core Features

1. Farm Profile
2. Farm Memory
3. Rotation Advisor
4. Climate Replay

## Technology Stack

- Python
- NASA POWER API
- Pandas / NumPy
- Streamlit
- Plotly
- SciPy
